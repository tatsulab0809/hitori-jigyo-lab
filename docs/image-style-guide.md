# ひとり事業ラボ 画像方針

- 人物を出す場合は、顔・髪・体・表情が普通に人として分かるキャラクターにする。
- 抽象的な丸い頭だけ、顔なのか後ろ姿なのか分からない人物は避ける。
- アイキャッチ内の文字は、切れやすいので原則入れない。
- 色はネイビー、ゴールド、白、薄いクリームを基調にする。
- きれいすぎるAI画像より、シンプルな漫画・4コマ寄りの親しみやすさを優先する。
- 同じ構図、同じ机、同じ人物配置を連続で使い回さない。
- 1枚ごとに場面を変える。例: 机で考える、客がサイトを見る、現場で写真を撮る、スマホで問い合わせを見る。
- 参考テイストは、表情のある人物、ノート、パソコン、小物、吹き出しが入った親しみやすい漫画調。
