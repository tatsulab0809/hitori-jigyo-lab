# LUKE Project First Week Plan

## Goal For Week 1

Create a minimum public site that can be used for affiliate service provider registration and future content publishing.

The first priority is not affiliate registration. The better order is:

1. Decide the concept.
2. Build the minimum site.
3. Publish it.
4. Register with affiliate service providers using the published site URL.

## Target State By The End Of Week 1

- Site name and concept are decided.
- GitHub, Cloudflare, Google, and domain direction are prepared.
- Git for Windows installed.
- Node.js and npm installed.
- Astro site foundation created.
- Local Astro build succeeded.
- Top page, article pages, categories, and legal pages exist.
- 3 to 5 initial articles are drafted or published.
- The site is published through Cloudflare Pages or a temporary public URL.
- Affiliate registrations can begin using the site URL.
