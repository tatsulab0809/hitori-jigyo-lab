# Phase 16: Affiliate application media kit

## Purpose

Create reusable copy for affiliate network applications, direct SaaS applications, and partnership inquiries.

## Changes

- Added `/media-kit/` with Japanese and English application text.
- Added reusable media description, promotion method, audience, compliance, and reapplication templates.
- Added common form answers for business type, industry focus, sales channels, audience location, and traffic size.
- Linked the media kit from the main navigation, footer, and `/for-partners/`.
- Added a Markdown copy kit at `docs/affiliate-application-copy-kit.md`.

## Use

Use `/media-kit/` when a partner manager needs to review the media positioning. Use `docs/affiliate-application-copy-kit.md` when copying text into application forms.
